# Course Exercises: Data Mining, Machine Learning, Deep Learning

This repository contains the exercises and notebooks I completed for the following courses:

* Data Mining — University of Verona (UNIVR)
* Machine Learning — Eindhoven University of Technology (TU/e)
* Deep Learning — Eindhoven University of Technology (TU/e)

## Repository Structure

* `data-mining/` — Notebooks and exercises for the Data Mining course (UNIVR).
* `machine-learning/` — Exercises and assignments for the Machine Learning course (TU/e). Some assignments and setup scripts can be found in the subfolder `machine-learning/Assignment_3_2026/`.
* `deep-learning/` — Notebooks and experiments for the Deep Learning course (TU/e).

## How to Use

1. Create and activate a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Install the dependencies (if available):

```bash
pip install -r machine-learning/Assignment_3_2026/requirements.txt
```

3. Launch JupyterLab or Jupyter Notebook and open the desired notebooks:

```bash
jupyter lab
# or
jupyter notebook
```
